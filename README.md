# Қауіпсіз файл сақтау және алмасу жүйесі

## Клиент жағында шифрланатын бұлттық қойма
    Бұл жоба файлдарды бұлтта қауіпсіз сақтауға және басқа пайдаланушылармен қорғалған түрде бөлісуге арналған. Файл серверге жіберілмес бұрын пайдаланушы құрылғысында шифрланады. Сервер шифрланған деректерді сақтайды, ал файлдың бастапқы мазмұнын ашу үшін қажетті құпия кілт пайдаланушының бақылауында болады.
## Жобаның мақсаты
    Пайдаланушыларға жеке және жұмыс файлдарын сақтау, жүктеп алу және алмасу кезінде олардың құпиялылығын қорғауға мүмкіндік беру.
## Жоспарланған мүмкіндіктер
- Пайдаланушыны тіркеу және жүйеге кіру.
- Файлдарды клиент құрылғысында шифрлау және шифрын ашу.
- Шифрланған файлдарды бұлттық қоймаға жүктеу.
- Файлдар мен бумаларды басқару.
- Таңдалған пайдаланушыларға файлға қолжетімділік беру.
- Ортақ қолжетімділікті басқару және қайтарып алу.
- Файл тұтастығын тексеру.
- Қауіпсіздік оқиғалары мен қолжетімділік әрекеттерін тіркеу.
