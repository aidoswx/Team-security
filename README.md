# Қауіпсіз файл сақтау және алмасу жүйесі

## Авторлар: Әділ Айдос, Абдусаттар Мұхамеджан.

## Клиент жағында шифрланатын бұлттық қойма
    Бұл жоба файлдарды бұлтта қауіпсіз сақтауға және басқа пайдаланушылармен қорғалған түрде бөлісуге арналған. 
    Файл серверге жіберілмес бұрын пайдаланушы құрылғысында шифрланады. 
    Сервер шифрланған деректерді сақтайды, ал файлдың бастапқы мазмұнын ашу үшін қажетті құпия кілт пайдаланушының бақылауында болады.
## Жобаның мақсаты
    Пайдаланушыларға жеке және жұмыс файлдарын сақтау, жүктеп алу және алмасу кезінде олардың құпиялылығын қорғауға мүмкіндік беру.
## Жоспарланған мүмкіндіктер
- Пайдаланушыны тіркеу және жүйеге кіру.
- Файлдарды клиент құрылғысында шифрлау және шифрын ашу.
- Шифрланған файлдарды бұлттық қоймаға жүктеу.
- Файлдар мен бумаларды басқару.
- Таңдалған пайдаланушыларға файлға қолжетімділік беру.
- Ортақ қолжетімділікті басқару және қайтарып алу.
- Файл тұтастығын тексеру.
- Қауіпсіздік оқиғалары мен қолжетімділік әрекеттерін тіркеу.
## Жұмыс істеу қағидасы
    1. Пайдаланушы құрылғысынан файлды таңдайды.
    2. Клиент файл үшін кездейсоқ шифрлау кілтін жасайды.
    3. Файл клиент жағында аутентификацияланған шифрлау алгоритмімен шифрланады.
    4. Серверге шифрланған файл, қажетті техникалық параметрлер және қорғалған файл кілті жіберіледі.
    5. Жүктеп алу кезінде клиент қорғалған кілтті ашады, файлдың тұтастығын тексереді және шифрын ашады.
    6. Бөлісу кезінде файл кілті алушының ашық кілті арқылы қорғалып, оған қолжетімді болады.
## Ұсынылатын технологиялар

Нақты технологиялық стек әлі бекітілмеген. Ықтимал нұсқалар:

- **Клиент:** React және TypeScript.
- **Сервер:** Node.js немесе Python негізіндегі API.
- **Дерекқор:** PostgreSQL.
- **Файл қоймасы:** S3 үйлесімді объектілік қойма.
- **Криптография:** Web Crypto API және тексерілген криптографиялық кітапханалар.
- **Орналастыру:** Docker және HTTPS қолдайтын кері прокси.
