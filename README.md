# Secure Cloud Storage — Қауіпсіз файл сақтау және алмасу жүйесі
## Жоба авторлары: Айдос & Мухамеджан  

## 1. Жоба туралы

**Secure Cloud Storage** — Java тілінде жасалатын файлдарды қауіпсіз сақтау және алмасуға арналған бұлттық қойма жүйесі.

**Мақсаты:** файлдарды клиент жағында шифрлап, серверде қорғалған түрде сақтау және пайдаланушылар арасында қауіпсіз алмасуды ұйымдастыру.

Жүйенің негізгі ерекшелігі — файл серверге жіберілмей тұрып шифрланады.

## 2. Негізгі мүмкіндіктер

- Файлдарды бұлттық қоймаға жүктеу.
- Файлдарды клиент жағында шифрлау.
- Шифрланған файлдарды серверде сақтау.
- Файлдарды жүктеп алу және дешифрлау.
- Пайдаланушылар арасында файл алмасу.
- Файлдарға қолжетімділікті басқару.

## 3. Қолданылған технологиялар

| Технология | Қызметі |
|---|---|
| Java 17+ | Негізгі бағдарламалау тілі |
| Spring Boot | Серверлік қосымшаны құру |
| JCA | Криптографиялық операцияларды орындау |
| REST API | Клиент пен сервер арасындағы байланыс |
| AES-GCM | Файлдарды шифрлау және тұтастығын тексеру |

## 4. Жүйенің архитектурасы

Жүйе клиент-сервер архитектурасына негізделген.

**Негізгі компоненттер:**

1. **Client** — файлды таңдайды, шифрлайды және серверге жібереді.
2. **EncryptionService** — файлдарды шифрлау және дешифрлау операцияларын орындайды.
3. **FileController** — клиенттен келетін HTTP сұраныстарын қабылдайды.
4. **FileService** — файлдарды басқару логикасын орындайды.
5. **StorageService** — шифрланған файлдарды сақтайды.
6. **SharingService** — файлдарға қолжетімділікті ұйымдастырады.


## 5. Негізгі кластар

| Класс | Қызметі |
|---|---|
| `User` | Пайдаланушы деректерін сақтау |
| `StoredFile` | Файл туралы ақпаратты сақтау |
| `EncryptionService` | Файлдарды шифрлау және дешифрлау |
| `FileController` | API сұраныстарын өңдеу |
| `FileService` | Файлдарды жүктеу және басқару |
| `StorageService` | Файлдарды қоймаға сақтау |
| `SharingService` | Файл алмасуды басқару |

## 6. Жүйенің жұмыс істеу алгоритмі

1. Пайдаланушы жүйеге кіреді.
2. Сақталатын файлды таңдайды.
3. Клиент файлды AES-GCM алгоритмі арқылы шифрлайды.
4. Шифрланған файл серверге жіберіледі.
5. Сервер файлды бұлттық қоймада сақтайды.
6. Пайдаланушы файлды қайта жүктей алады.
7. Клиент файлды қажетті кілт арқылы дешифрлайды.

## 7. Файлдарды шифрлау механизмі

Жобада файлдардың құпиялылығын қамтамасыз ету үшін **AES-GCM** алгоритмін қолдану жоспарланған.

**Шифрлау процесі:**

- Файл клиент құрылғысында оқылады.
- Құпия кілт арқылы шифрланады.
- Шифрланған деректер серверге жіберіледі.
- Сервер файлдың бастапқы мазмұнын көрмейді.

**Дешифрлау процесі:**

- Шифрланған файл серверден жүктеледі.
- Клиент қажетті құпия кілтті қолданады.
- Файл бастапқы қалпына келтіріледі.

Құпия кілт серверге ашық түрде берілмеуі тиіс.

## 8. Файл алмасу жүйесі

Жүйе пайдаланушылар арасында файлдармен қауіпсіз алмасуды ұйымдастыруға арналған.

**Жұмыс принципі:**

1. Пайдаланушы файлды таңдайды.
2. Файлға қолжетімділік рұқсатын береді.
3. Басқа пайдаланушы файлды жүктейді.
4. Рұқсат етілген пайдаланушы файлды өз құрылғысында дешифрлайды.

Файл алушыға дешифрлау кілтін қауіпсіз жеткізу механизмі бөлек қарастырылуы қажет.

## 9. Қауіпсіздік жүйесі

Жүйенің қауіпсіздігі бірнеше принципке негізделеді:

- **Client-Side Encryption** — файл клиент жағында шифрланады.
- **Confidentiality** — файл мазмұны бөгде адамдардан қорғалады.
- **Integrity** — AES-GCM файл деректерінің өзгергенін анықтауға мүмкіндік береді.
- **Access Control** — файлдарға қолжетімділік шектеледі.
- **Key Management** — шифрлау кілттері қауіпсіз басқарылуы тиіс.

## 11. Жобаның артықшылықтары мен кемшіліктері

**Артықшылықтары:**

- Файлдар клиент жағында шифрланады.
- Серверде файлдардың шифрланған нұсқасы сақталады.
- Java криптографиялық кітапханалары қолданылады.
- Жүйені кеңейтуге мүмкіндік бар.

**Кемшіліктері:**

- Кілттерді басқару күрделі.
- Кілт жоғалса, файлды қалпына келтіру қиын немесе мүмкін емес.
- Шифрлау қосымша есептеу ресурстарын қажет етеді.
- Файл алмасу үшін қауіпсіз кілт жеткізу механизмі қажет.

## 12. Болашақта дамыту мүмкіндіктері

- JWT арқылы пайдаланушыларды аутентификациялау.
- Файлдарды топтар арасында бөлісу.
- Файл нұсқаларын сақтау.
- Файлдарға қолжетімділік мерзімін орнату.
- Веб-интерфейс жасау.
- Бұлттық сақтау қызметтерімен интеграциялау.

## 13. Қорытынды

**Secure Cloud Storage** — файлдарды клиент жағында шифрлау арқылы қауіпсіз сақтау және алмасу принциптерін жүзеге асыруға бағытталған жоба.

Жоба Java, Spring Boot және JCA технологияларын пайдаланып, клиент-сервер архитектурасын, криптографияны және файлдарды басқаруды тәжірибеде үйренуге мүмкіндік береді.
